# 截点

在任意 macOS 应用里选中一句话，默认按 `⌥ R`（可在“设置”中自定义快捷键），为它填写截止时间。截下来的原话和期限保存在本机；开启 Apple 日历同步后，带有截点标记的关联事件可以在 Mac、iPhone、iPad 间双向更新。

## 构建与启动

```sh
swift scripts/generate-icon.swift "$PWD"
sh scripts/build-app.sh
open "dist/截点.app"
```

开发时可用一条命令重新构建并重启应用：

```sh
sh scripts/restart-app.sh
```

首次按默认快捷键 `⌥ R`（或在“设置”中自定义的组合键）后，在“系统设置 → 隐私与安全性 → 辅助功能”中允许“截点”。如果没有授予权限，截取面板仍会打开，可以手动输入事项；也可以使用剪贴板路径，它会短暂模拟 `⌘ C` 并恢复原剪贴板内容。

要同步 Apple 日历：打开“设置 → Apple 日历同步”，允许完整日历访问，选择一个可写日历并打开“允许同步到 Apple Calendar”。只有 iCloud 日历会跨设备同步；普通日历事件不会自动导入。首次让已有事项进入日历，需要在设置中明确点击“同步现有事项”。

开启同步后，新建事项保存成功会自动加入所选日历；已有事项仍需手动点击“同步现有事项”。事项到期时会收到本地通知；创建待办时还可设置多次提前提醒，也可以为单次提前提醒选择自定义日期和时间。

截点只同步带有 `jiedian://item/<UUID>` 标记的关联事件。日历端修改标题或开始时间会回写截点；日历端删除事件只解除关联并保留本地事项，避免误删数据。关闭自动同步不会删除已有日历事件。

事项数据位于 `~/Library/Application Support/Jiedian/items.json`。日历事件由系统 Calendar/EventKit 管理，不会把事项 JSON 上传到截点服务器；项目本身没有服务器或账号。开发时可设置 `JIEDIAN_STORAGE_PATH` 指向临时文件，避免污染日常数据。

## 验证

```sh
swift run JiedianChecks
```

检查标记解析、事件投影、事项校验、按期限排序、持久化、逾期、完成、恢复与截图附件。
