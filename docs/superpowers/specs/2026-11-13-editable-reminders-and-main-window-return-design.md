# 待办提醒编辑与返回主窗口设计

## 意图

让已创建待办可以编辑提醒次数、提醒方式、提前天数和时刻；让用户可以从创建待办面板直接返回主窗口。

## 目标

- 创建面板和编辑面板复用同一提醒编辑组件。
- 相对提醒的提前天数支持数字输入，并与提醒时间控件紧凑并排。
- 自定义提醒日期和时间使用紧凑字段控件并排显示。
- 编辑保存提醒数组，并沿用现有通知更新流程；自定义提醒晚于或等于截止时间时阻止保存。
- 创建面板提供“回到主窗口”按钮，关闭面板后显示主窗口。

## 非目标

- 不更改提醒数据格式、默认提醒计划、本地通知规则或日历同步行为。
- 不调整创建、取消和关闭面板的其他行为。

## 约束与实现决定

- 使用现有 SwiftUI 和设计系统样式，保留 0–30 次提醒、1–365 天的范围。
- 返回主窗口时清除待处理的自动隐藏标记，再关闭创建面板并调用现有主窗口显示逻辑。
- 回主窗口视为关闭未保存的创建面板，不保存当前草稿。

## 方案

1. **创建和编辑共用提醒组件（采用）**：提取共享编辑器，使两处表单的次数、相对/自定义模式、验证和控件布局一致。以紧凑日期字段替换独占一行的图形日历，满足日期与时间并排。
2. **在编辑面板复制一套控件（不采用）**：初次改动较少，但两处行为和样式容易分叉，也无法保证组件一致。
