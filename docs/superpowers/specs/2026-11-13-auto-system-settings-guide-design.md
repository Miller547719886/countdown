# 首次启动自动打开系统设置向导设计

## 意图

首次安装并启动“截点”时，继续显示现有的应用内“初次使用设置”向导；如果当前进程尚未获得辅助功能权限，则在向导显示后自动打开 macOS「系统设置 → 隐私与安全性 → 辅助功能」。这样用户无需先猜到要点击哪个按钮，就能完成选区捕获所需的授权。

## 目标

- 首次运行且尚未授权辅助功能时，自动打开辅助功能设置页。
- 保留现有向导、截图说明、重新检查和手动“打开系统设置”入口。
- 关闭或完成向导后，后续启动不再自动打开系统设置。
- 如果已有辅助功能授权，首次向导仍可展示，但不打开无关的系统设置页。

## 非目标与约束

- 不自动修改任何系统权限，不调用会强制授权的 API。
- 不改变现有的 UserDefaults 关闭标记、手动入口或权限轮询。
- 不在每次启动、应用更新或用户从设置页手动打开向导时跳转系统设置。
- 继续使用现有的 `x-apple.systempreferences` 深链接，并保留失败状态文案。

## 方案

1. **首次向导展示后自动深链接（采用）**：复用 `AppCoordinator.showFirstRunSetupGuideIfNeeded()`，先展示向导，再在主队列中检查 `AXIsProcessTrusted()`；未授权时调用现有 `openAccessibilitySettings()`。改动小、与已有向导生命周期一致。
2. **只触发系统权限提示**：使用 Accessibility 提示 API，不显示应用内向导。缺少现有截图和屏幕录制/日历步骤，不采用。
3. **每次启动打开系统设置**：无需状态判断，但会打扰已使用用户，不符合首次安装语义。

## 行为顺序

1. `configure(store:)` 调用现有首次运行判定。
2. 首次且未关闭时，异步显示应用内向导。
3. 向导显示后刷新辅助功能状态；若未授权，自动打开辅助功能深链接。
4. 用户返回应用后可点击“重新检查”，关闭向导仍写入现有一次性标记。
